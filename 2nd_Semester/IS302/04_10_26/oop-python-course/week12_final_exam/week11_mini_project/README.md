# Student Information System (Week 11 Mini Project)

Project: Student Information System (Python, OOP)

Description
- A simple menu-driven student information system demonstrating OOP, file handling, and exception handling.

Features
- Add Student
- View Students
- Search Student by ID

How to run
1. Open a terminal in the `week11_mini_project` folder.
2. Run:

```bash
python main.py
```

Sample usage

STUDENT INFORMATION SYSTEM
1 Add Student
2 View Students
3 Search Student
4 Exit
Enter choice: 1
Enter Student ID: 2023-001
Enter Name: Maria
Enter Course: BSIS
Student added successfully
