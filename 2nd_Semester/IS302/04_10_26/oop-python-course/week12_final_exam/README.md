# Inventory Management System (Week 12 Final Exam)

Description
- A simple Inventory Management System demonstrating OOP (encapsulation), file handling, and exception handling.

Features
- Add Product
- View Products
- Search Product by ID
- Update Product Quantity

How to run
1. Open a terminal in the `week12_final_exam` folder.
2. Run:

```bash
python main.py
```
